# Contributing

Thanks for your interest in improving this NLP project.

1. Open an issue describing the proposed improvement.
2. Fork the repository and create a focused branch.
3. Keep data preprocessing and evaluation reproducible; document random seeds and splits.
4. Do not commit secrets, large generated checkpoints, or private SMS data.
5. Run the relevant notebook end to end and describe the results in your pull request.

This repository is an educational model comparison. Report measured results, not unverified deployment claims.
