# Security and data handling

- Do not commit credentials, private messages, or user-identifying SMS records.
- Review dataset licensing and privacy before redistribution.
- Treat incoming text as untrusted input in any future deployed application.
- Avoid loading untrusted serialized model files.
- The current repository is a notebook-based educational experiment, not a production spam-filter service.

Please report security issues privately to the repository owner instead of publishing sensitive details in an issue.
